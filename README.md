# Trabalho final de Programação Orientada a Objetos

Sistema desenvolvido em Java para monitoramento e controle de estufas agrícolas inteligentes. O projeto permite o gerenciamento de estufas, sensores e culturas, realizando a coleta de dados ambientais, geração de alertas e controle automatizado de dispositivos. Também conta com cálculo de médias, geração de relatórios e persistência dos dados em arquivos.
